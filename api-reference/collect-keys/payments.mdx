---
title: GET /deposits (recaudos Bre-B por cliente)
description: Conciliar los pagos Bre-B de cada cliente tuyo
api: 'GET https://consola.mouvlatam.com/api/deposits'
---

El listado de depósitos, filtrado a los recaudos **Bre-B** y — para agregadores — **por cliente tuyo**. Cada pago trae la llave que lo recibió con tu `externalId`: la conciliación es un join directo contra tu sistema. **Scope**: `READ`.

## Query params (los relevantes para agregadores)

| Param | Tipo | Significado |
|---|---|---|
| `rail` | string | `BREB` — solo recaudos Bre-B |
| `externalId` | string | Solo los pagos a las llaves de ESE cliente tuyo |
| `brebKeyId` | string | Alternativa: filtrar por el id de una llave puntual |
| `limit` | number | Default 20, máximo 100 |
| `page` | number | Paginación por página (0-based) |

- `brebKey` es `null` en depósitos que no entraron por una llave (por ejemplo PSE).
- `status`: `ASSIGNED` = acreditado a tu saldo. Otros valores posibles: `UNASSIGNED`, `REVERSED`, `PENDING_CONFIRM`, `EXPIRED`.
- Los montos van como **string en centavos** (precisión exacta).
