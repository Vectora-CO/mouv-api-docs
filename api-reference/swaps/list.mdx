---

Lista las operaciones de tu empresa, de la más reciente a la más antigua.

**Scope requerido**: `SWAP`.

## Query params

<ParamField query="status" type="string">
  Filtra por estado: `PROCESANDO`, `COMPLETADO`, `CANCELADO` o `EN_REVISION`. Otro valor responde `400 INVALID_REQUEST`.
</ParamField>

<ParamField query="side" type="string">
  `BUY` (la única operación disponible). Un valor desconocido responde `400 INVALID_REQUEST`.
</ParamField>

<ParamField query="from" type="string">
  Inicio del rango de `createdAt` (ISO 8601, inclusive).
</ParamField>

<ParamField query="to" type="string">
  Fin del rango de `createdAt` (ISO 8601, inclusive).
</ParamField>

<ParamField query="page" type="integer">
  Página, desde 1. Por defecto 1.
</ParamField>

<ParamField query="limit" type="integer">
  Resultados por página, de 1 a 100. Por defecto 20.
</ParamField>

## Errores

| HTTP | `error` | Cuándo y qué hacer |
|---|---|---|
| 400 | `INVALID_REQUEST` | `status`, `side`, `from` o `to` inválidos. Corrige el parámetro |
| 401 | `INVALID_API_KEY` | Llave inválida o revocada |
| 403 | `INSUFFICIENT_SCOPE` | La llave no es scope `SWAP` |
| 403 | `IP_NOT_ALLOWED` | La petición viene de una IP no permitida para la llave |
| 503 | `SWAP_UNAVAILABLE` | Reintenta con backoff |
