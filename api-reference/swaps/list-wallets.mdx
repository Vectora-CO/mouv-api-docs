title: GET /swaps/wallets

Lista las billeteras vigentes de tu empresa donde puedes recibir USDT.

**Scope requerido**: `SWAP`.

<Warning>
Por defecto las billeteras se registran y eliminan **desde el dashboard**, con rol `ADMIN` y código 2FA. Una llave `SWAP` común solo puede listarlas y consultarlas: un intento de alta o baja responde `403 WALLET_PERMISSION_REQUIRED`. Si Mouv habilita la gestión por API para tu empresa, una llave con el permiso **Gestionar billeteras** (e IPs autorizadas) puede usar [`POST /swaps/wallets`](/api-reference/swaps/create-wallet) y [`DELETE /swaps/wallets/:walletId`](/api-reference/swaps/delete-wallet). Ver la [guía](/guides/swap-cop-usdt#registrar-billeteras-por-api-opcional).
</Warning>

Solo lista billeteras **vigentes**; las eliminadas no aparecen (consúltalas por id con [`GET /swaps/wallets/:walletId`](/api-reference/swaps/get-wallet)).

## Response 200

```json
{
  "wallets": [
    {
      "id": "5f0c2a64-7a5b-4d0e-9f3a-0c1d2e3f4a5b",
      "network": "TRON",
      "address": "TJRabPrwbZy45sbavfcjinPJC18kjpRTv8",
      "label": "Tesorería",
      "status": "DISPONIBLE",
      "availableFrom": "2026-10-08T15:00:00.000Z",
      "createdAt": "2026-10-08T15:00:00.000Z",
      "origin": "PANEL",
      "apiKeyPrefix": null
    }
  ]
}
```

| Campo | Tipo | Descripción |
|---|---|---|
| `id` | string | Úsalo como `walletId` al cotizar |
| `network` | string | `TRON` o `POLYGON` |
| `address` | string | Dirección de la billetera |
| `label` | string \| null | Nombre que le diste al registrarla |
| `status` | string | `EN_REVISION`, `EN_ESPERA` o `DISPONIBLE` |
| `availableFrom` | string | Fecha ISO 8601 desde la que la billetera puede operar, si además está aprobada |
| `createdAt` | string | Fecha de registro (ISO 8601) |
| `origin` | string | `PANEL` (registrada en el dashboard) o `API` |
| `apiKeyPrefix` | string \| null | Prefijo visible de la llave que la registró; `null` si `origin` es `PANEL` |

| `status` | Significado |
|---|---|
| `EN_REVISION` | Pendiente de la revisión de cumplimiento. Todavía no opera |
| `EN_ESPERA` | Aprobada, en período de espera hasta `availableFrom` (solo si tu empresa tiene configurado un período de espera; por defecto no hay) |
| `DISPONIBLE` | Lista para operar: es la única que acepta cotizaciones |

La billetera es usable apenas queda aprobada; no hay espera adicional por defecto.

## Errores

| HTTP | `error` | Cuándo y qué hacer |
|---|---|---|
| 401 | `INVALID_API_KEY` | Llave inválida o revocada |
| 403 | `INSUFFICIENT_SCOPE` | La llave no es scope `SWAP` |
| 403 | `IP_NOT_ALLOWED` | La petición viene de una IP no permitida para la llave |
| 503 | `SWAP_UNAVAILABLE` | Reintenta con backoff |
